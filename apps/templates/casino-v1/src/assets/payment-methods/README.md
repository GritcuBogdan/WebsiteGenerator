# Payment method logos

Drop real logo files here, named after the method's key (any image extension —
svg, png, webp, jpg all work). `PaymentMethods.astro` picks them up
automatically at build time; no code change needed.

| Key             | Method        |
| ---------------- | ------------- |
| `visa`           | Visa          |
| `mastercard`     | Mastercard    |
| `paypal`         | PayPal        |
| `skrill`         | Skrill        |
| `neteller`       | Neteller      |
| `trustly`        | Trustly       |
| `apple-pay`      | Apple Pay     |
| `google-pay`     | Google Pay    |
| `bitcoin`        | Bitcoin       |
| `bank-transfer`  | Bank Transfer |

Example: `visa.svg` or `visa.png` both work — just match the key.
