{{BRAND_NAME}}in tilille kirjaudutaan rekisteröinnissä käytetyllä sähköpostiosoitteella ja salasanalla. Avaa kirjautumislomake, syötä tiedot huolellisesti ja lähetä lomake kerran. Vanhan salasanan toistuva kokeileminen voi käynnistää lyhyen turvatarkistuksen.

Kun tili avautuu, tarkista ensin saldo, valuutta ja viimeisin toiminta. Näet samalla mahdollisen keskeneräisen tunnistautumisen, odottavan maksun tai aktiivisen kampanjan. Tilin asetuksista pitäisi löytyä profiili, talletusrajat, nostohistoria ja vastuullisen pelaamisen työkalut.

| Tarkistus | Suositeltu toiminta |
| --- | --- |
| Sähköposti | Käytä tiliin liitettyä osoitetta tarkassa muodossa |
| Salasana | Älä hyväksy selaimen vanhaa automaattista arvoa |
| Laite | Vältä julkista tietokonetta ja kirjaudu ulos käytön jälkeen |
| Turvailmoitus | Lue ilmoitus ennen pelien avaamista |
| Epäonnistunut yritys | Käytä salasanan palautusta arvailun sijaan |

Älä tallenna salasanaa yhteiskäyttöiselle laitteelle. Jos tili ei avaudu palautuksen jälkeen, ota yhteys tukeen tilin sähköpostiosoitteesta. Älä lähetä salasanaa tai koko maksukortin numeroa.
