{{BRAND_NAME}}in kampanjakoodi liittää tarjouksen tiettyyn tilitoimintoon. Se voi avata tervetuliaisbonuksen, lisätalletuksen tai ilmaiskierroksia. Koodi ei korvaa ehtoja, joten tarkista aktivointi, talletus, voimassaolo ja mahdollinen rajoitus.

| Tarkistus | Miksi se merkitsee |
| --- | --- |
| Kirjoitusasu | Koodi voi olla kirjainkoolla tarkka |
| Tilin tila | Osa koodeista koskee vain uusia tilejä |
| Ajankohta | Aktivointi voi olla tehtävä ennen talletusta |
| Maksu | Kampanja voi vaatia vähimmäistalletuksen |
| Tulos | Varmista että hyvitys näkyy tilillä |

Jos koodi ei toimi, älä syötä sitä toistuvasti. Tarkista kampanjasivu ja kysy tuelta virheilmoituksen kanssa.
