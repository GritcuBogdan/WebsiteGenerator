Kampanjakoodi kannattaa syöttää vasta, kun tiedät mitä se aktivoi. {{BRAND_NAME}}in koodi voi liittyä tervetuliaisbonukseen, tiettyyn talletuspäivään tai ilmaiskierroksiin. Koodin käyttäminen voi myös sitoa tilin tarjouksen ehtoihin, joten tarkista säännöt ennen hyväksymistä.

| Ennen koodia | Tarkistus |
| --- | --- |
| Koodi | Kirjoitusasu ja mahdollinen kirjainkoko |
| Tili | Onko kampanja tarkoitettu uusille pelaajille |
| Talletus | Mikä vähimmäismäärä vaaditaan |
| Ajankohta | Milloin koodi vanhenee |
| Hyvitys | Näkyykö tarjous tilillä ennen pelaamista |

Jos hyvitys ei ilmesty, lopeta pelaaminen ja ota yhteys tukeen. Älä yritä korjata tilannetta uudella talletuksella ennen kuin ensimmäinen tilanne on selvitetty.
