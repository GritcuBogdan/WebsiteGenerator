Kampanjakoodi on hyödyllinen vain, jos se sopii tilin tilanteeseen. Tarkista ennen käyttöä, onko koodi tarkoitettu uudelle asiakkaalle, vaatiiko se tietyn talletuksen ja millä pelillä mahdolliset ilmaiskierrokset toimivat. Kuvakaappaus kampanjasta auttaa, jos hyvitys ei ilmesty oikein.

| Koodin jälkeen | Tarkistus |
| --- | --- |
| Tili | Näkyykö kampanjan nimi asetuksissa |
| Kassa | Täyttyykö talletusehto |
| Peli | Onko valittu peli hyväksytty |
| Eteneminen | Näkyykö bonus tai kierrokset |
| Tuki | Onko virheilmoitus tallessa |

Älä kasvata talletusta virheen vuoksi. Odota tuen vastausta ja pidä oma budjetti voimassa.
