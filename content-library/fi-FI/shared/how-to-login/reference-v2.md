Kun kirjaudut {{BRAND_NAME}}iin, tarkista ensin että olet virallisella sivulla. Syötä tiliin liitetty sähköposti ja nykyinen salasana. Jos palvelu pyytää vahvistuskoodia, käytä vain omaan sähköpostiisi tai laitteeseesi tullutta koodia.

| Tilanne | Toiminta |
| --- | --- |
| Oikea sivu | Tarkista osoite ennen tietojen syöttämistä |
| Salasana unohtui | Avaa palautuslinkki, älä arvaa toistuvasti |
| Uusi laite | Tarkista mahdollinen turvailmoitus |
| Tilin avaaminen onnistui | Katso saldo ja viimeisin toiminta |
| Istunto päättyy | Kirjaudu ulos ja sulje selain |

Älä anna kirjautumistietoja tuelle tai toiselle henkilölle. Jos näet vieraan laitteen ilmoituksen, vaihda salasana virallisella sivulla ja ilmoita asiasta.
