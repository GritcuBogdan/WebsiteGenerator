{{BRAND_NAME}}in ilmaiskierrokset antavat tietyn määrän kierroksia ilman erillistä panosta. Tarkista kierrosten määrä, peli, voimassaoloaika, voittojen muoto ja kierrätysehto.

| Kohta | Mitä varmistaa |
| --- | --- |
| Määrä | Kuinka monta kierrosta hyvitetään |
| Peli | Missä nimikkeessä kierrokset toimivat |
| Voimassaolo | Milloin käyttämättömät kierrokset poistuvat |
| Voitot | Muuttuvatko tulokset rahaksi vai bonus saldoksi |
| Kierrätys | Mikä vaatimus koskee tuloksia |

Käytä kierrokset ilmoitetussa pelissä ja tarkista kampanjasivu ennen aloittamista. Kierrokset ovat tapa tutustua peliin, eivät lupaus voitosta.
