Mobiilipelaaminen {{BRAND_NAME}}issa tapahtuu mukautuvassa selaimessa. Pelit, kassa, tili, tuki ja vastuullisen pelaamisen työkalut pitäisi löytää myös pieneltä näytöltä.

| Tarkistus | Miksi se merkitsee |
| --- | --- |
| Selain | Käytä tuettua ajantasaista selainta |
| Yhteys | Vakaa yhteys vähentää keskeytyksiä |
| Ohjaimet | Painikkeiden ja voittotaulukon on oltava selkeitä |
| Kassa | Maksut on voitava avata ilman työpöytänäkymää |
| Turvallisuus | Käytä laitteen lukitusta ja yksityistä verkkoa |

Testaa yksi peli, kassa ja tukisivu ennen pidempää istuntoa. Älä käytä julkista verkkoa maksuissa ja pidä sama budjetti kuin muilla laitteilla.
