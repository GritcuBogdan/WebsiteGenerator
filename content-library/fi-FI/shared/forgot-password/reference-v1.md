Jos unohdat {{BRAND_NAME}}in salasanan, käytä virallisen kirjautumissivun palautuslinkkiä. Anna tilin sähköposti ja tarkista myös roskaposti. Avaa linkki vain, jos lähettäjä ja osoite kuuluvat palveluun.

| Vaihe | Hyvä käytäntö |
| --- | --- |
| Pyyntö | Käytä tiliin liitettyä sähköpostia |
| Viesti | Tarkista lähettäjä ennen linkkiä |
| Uusi salasana | Käytä yksilöllistä salasanaa |
| Tarkistus | Katso viimeisin toiminta kirjautumisen jälkeen |
| Tuki | Ota yhteys, jos viesti ei saavu |

Älä jaa palautuslinkkiä. Jos saat odottamattoman viestin, vaihda salasana virallisella sivulla ja ilmoita asiasta.
