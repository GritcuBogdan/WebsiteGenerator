{{BRAND_NAME}}in tili ja maksuhäiriöitä voi rajata virheilmoituksen, laitteen ja epäonnistuneen toiminnon avulla. Tarkista yhteys, selaimen tila ja tilin ilmoitukset. Älä toista maksua, jos ensimmäinen on vielä odottamassa.

| Ongelma | Ensimmäinen tarkistus |
| --- | --- |
| Kirjautuminen hylätään | Sähköposti, salasana ja palautus |
| Peli ei lataudu | Selain, yhteys ja pelin tila |
| Saldo näyttää väärältä | Toiminta, maksu ja valuutta |
| Maksu odottaa | Kassan ilmoitus ja käsittelyaika |
| Tili on rajoitettu | Tunnistautumis tai turvailmoitus |

Jos ongelma jatkuu, kirjaa aika, laite ja viesti ja lähetä tiedot tuelle. Älä liitä salasanaa tai koko kortin numeroa.
