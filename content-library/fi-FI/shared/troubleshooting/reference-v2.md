Yleisimmät tekniset ongelmat {{BRAND_NAME}}in käytössä liittyvät joko yhteyteen, selaimeen tai vanhentuneeseen istuntoon, eivät varsinaiseen tiliin. Ennen yhteydenottoa tukeen kannattaa kokeilla muutamaa peruskeinoa itse.

| Ongelma | Kokeiltava ratkaisu |
| --- | --- |
| Sivusto ei lataudu | Tarkista yhteys ja päivitä sivu |
| Peli jumittuu | Sulje ja avaa peli uudelleen |
| Kirjautuminen katkeaa | Kirjaudu ulos ja takaisin sisään |
| Painikkeet eivät reagoi | Tyhjennä selaimen välimuisti |

Jos ongelma toistuu useilla laitteilla tai yhteyksillä, syy ei todennäköisesti ole omassa laitteessa vaan liittyy palveluun itseensä. Tällöin kannattaa ottaa yhteyttä tukeen ja kertoa, milloin ongelma alkoi ja millä toiminnolla se ilmenee.

Talletus tai nosto kannattaa vahvistaa vain kerran ongelman aikana, sillä toistuva yrittäminen voi johtaa päällekkäisiin tapahtumiin, joiden selvittäminen jälkikäteen vie enemmän aikaa.
