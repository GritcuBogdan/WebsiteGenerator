No deposit hyvityksessä tärkeintä on tietää, mitä voitolla tarkoitetaan. Alkuperäinen hyvitys ei yleensä muutu suoraan nostettavaksi rahaksi. Ensin on täytettävä kierrätys, käytettävä hyväksyttyjä pelejä ja pysyttävä kampanjan aikarajassa. Vasta sen jälkeen mahdollinen muunnettava saldo voidaan tarkistaa nostoa varten.

| Vaihe | Mitä tehdä |
| --- | --- |
| Aktivointi | Lue ehdot ennen aloittamista |
| Peli | Käytä vain hyväksyttyjä nimikkeitä |
| Seuranta | Tarkista kierrätyksen eteneminen |
| Aikaraja | Lopeta kampanja ajoissa, jos ehto ei täyty |
| Nosto | Varaudu henkilöllisyyden tarkistukseen |

Pidä kampanja erillään omasta rahasta ja kysy tuelta, jos ehto tai saldo ei vastaa näkyvää tietoa.
