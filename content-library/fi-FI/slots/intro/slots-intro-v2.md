Kolikkopelien valikoimaa kannattaa käyttää kuin kirjastoa. Aloita suodattimesta, avaa pelin säännöt ja tarkista panoksen vaikutus ennen ensimmäistä kierrosta. {{BRAND_NAME}}in lobby on hyödyllinen silloin, kun pelin perustiedot löytyvät samasta paikasta kuin käynnistyspainike.

| Ennen avaamista | Tarkistus |
| --- | --- |
| Teema | Sopisiko peli omaan makuun |
| Panos | Mahtuuko valittu arvo budjettiin |
| Ominaisuudet | Ymmärrätkö bonuskierrokset ja symbolit |
| Sääntö | Löytyykö tieto suurimmasta voitosta |
| Laite | Toimiiko peli omalla näytöllä |

Pidä valinta rauhallisena. Peliä ei tarvitse vaihtaa vain siksi, että ensimmäiset kierrokset eivät tuota tulosta.
