Pelivalmistajan suodatin on hyvä työkalu silloin, kun haluat rajata suuren valikoiman pienemmäksi. Se ei kuitenkaan kerro yksin pelin riskitasoa. Tarkista aina yksittäisen nimikkeen panokset, säännöt ja ominaisuudet.

| Valmistajan jälkeen | Seuraava tarkistus |
| --- | --- |
| Löydät tutun studion | Avaa yksittäisen pelin tietopaneeli |
| Näet paljon nimikkeitä | Suodata panosalueen mukaan |
| Pidät tietystä teemasta | Vertaa volatiliteettia |
| Löydät uuden pelin | Kokeile demoa, jos se on tarjolla |
| Säännöt ovat epäselvät | Kysy tuelta ennen oikeaa panosta |

Näin valmistajan nimi auttaa haussa, mutta lopullinen valinta perustuu pelin omiin sääntöihin.
