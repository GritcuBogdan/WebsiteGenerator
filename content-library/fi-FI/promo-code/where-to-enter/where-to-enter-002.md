Kampanjakoodin, esimerkiksi {{PROMO_CODE}}, syöttöpaikka riippuu siitä, missä vaiheessa asiointia ollaan {{BRAND_NAME}}issa. Seuraava taulukko kokoaa yleisimmät tilanteet.

| Tilanne | Missä koodi syötetään |
| --- | --- |
| Uusi tili | Rekisteröitymislomakkeen oma kenttä |
| Talletus | Kassan yhteydessä ennen maksun vahvistusta |
| Olemassa oleva tili | Kampanjasivu tai tilin asetukset |
| Erillinen kampanja | Kampanjan oma laskeutumissivu |

Koodi kannattaa syöttää tarkasti samassa muodossa kuin se on ilmoitettu, sillä ylimääräiset välilyönnit tai väärä kirjainkoko voivat estää sen toimimisen. Jos koodi hyväksytään, sen pitäisi näkyä vahvistuksena joko heti ruudulla tai myöhemmin tilin tapahtumatiedoissa.

Jos koodikenttää ei löydy odotetusta paikasta, kannattaa tarkistaa, onko tarjous ylipäätään sidottu koodiin vai aktivoituuko se automaattisesti ilman erillistä syöttöä.
