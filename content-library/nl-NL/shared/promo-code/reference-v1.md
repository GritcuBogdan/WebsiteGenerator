Een promotiecode bij {{BRAND_NAME}} koppelt een campagne aan een accountactie. De code kan een welkomstbonus, reload of gratis spins openen. Controleer de activatie, storting, geldigheid en limiet, want de code vervangt de voorwaarden niet.

| Controle | Waarom |
| --- | --- |
| Spelling | Codes moeten exact zijn |
| Account | Sommige codes zijn alleen voor nieuwe leden |
| Moment | Activatie kan vóór de storting nodig zijn |
| Betaling | Een minimumstorting kan gelden |
| Resultaat | Controleer of de beloning zichtbaar is |

Werkt de code niet, voer hem dan niet herhaaldelijk in. Controleer de promotiepagina en vraag support met de foutmelding om hulp.
