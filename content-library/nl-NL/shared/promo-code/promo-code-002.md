Een promotiecode bij {{BRAND_NAME}} lijkt een kleine handeling, maar de code zelf bepaalt vaak welke aanbieding je krijgt en onder welke voorwaarden. Voer de code daarom altijd precies in zoals hij is opgegeven, want een extra spatie of een verkeerde hoofdletter kan er al voor zorgen dat hij niet wordt herkend.

Controleer voordat je de code invoert ook of hij nog geldig is en of hij bij jouw situatie past. Sommige codes zijn alleen voor nieuwe spelers, andere gelden juist voor een storting die je al langer als klant doet. Een code die niet bij je account past, wordt vaak gewoon geweigerd zonder duidelijke reden.

Werkt de code niet, blijf hem dan niet herhaaldelijk invoeren. Controleer eerst de promotiepagina op de actuele voorwaarden en neem pas daarna, met de foutmelding erbij, contact op met support als het probleem aanhoudt.
