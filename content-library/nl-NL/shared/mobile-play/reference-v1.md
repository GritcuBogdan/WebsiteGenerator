Mobiel spelen bij {{BRAND_NAME}} loopt via een responsive browser. Games, cashier, account, support en hulpmiddelen voor verantwoord spelen moeten ook op een klein scherm bereikbaar blijven.

| Controle | Waarom |
| --- | --- |
| Browser | Gebruik een actuele ondersteunde browser |
| Verbinding | Een stabiele verbinding voorkomt onderbrekingen |
| Bediening | Knoppen en winplan moeten leesbaar zijn |
| Cashier | Betalingen moeten zonder desktopweergave werken |
| Veiligheid | Gebruik schermvergrendeling en een privéverbinding |

Test vóór een lange sessie een spel, de cashier en support. Gebruik geen openbaar wifi voor betalingen en houd hetzelfde budget aan.
