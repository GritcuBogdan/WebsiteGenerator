Lukt het inloggen bij {{BRAND_NAME}} niet meer omdat de code van je tweestapsverificatie wordt geweigerd, controleer dan eerst de tijdsinstelling van je telefoon. De codes van een authenticatie app zijn tijdgebonden, en een klok die niet synchroon loopt, is een veelvoorkomende reden waarom een verder correcte code toch wordt afgewezen.

Werk je met een code per sms, controleer dan of het telefoonnummer in je account nog actueel is en of je bereik hebt. Duurt het ontvangen van de code langer dan een paar minuten, vraag dan een nieuwe code aan in plaats van te blijven wachten op de eerste.

Ben je je telefoon of authenticatie app volledig kwijt, gebruik dan de herstelcodes die je bij het instellen hebt bewaard om weer toegang te krijgen. Heb je die niet bewaard, neem dan contact op met support vanaf je geregistreerde e mailadres. Reken in dat geval op een uitgebreidere identiteitscontrole, omdat support dan op een andere manier moet vaststellen dat jij de rechtmatige accounthouder bent.
