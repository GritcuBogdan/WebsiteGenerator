Sommige promoties bij {{BRAND_NAME}} zijn niet aan de registratie gekoppeld, maar aan een storting die je op een later moment doet. In dat geval voer je de {{PROMO_CODE}} in via de kassa, op het moment dat je het stortingsbedrag opgeeft. Zoek naar een apart veld voor een code of bonusaanbieding, meestal direct onder of naast het invoerveld voor het bedrag.

Wordt de code niet geaccepteerd, controleer dan eerst op tikfouten en op eventuele spaties voor of na de code. Ga ook na of de code nog geldig is en of hij bij het gekozen betaalmethode of stortingsbedrag past, want sommige codes zijn aan een minimumstorting gekoppeld.

Is de code correct ingevoerd maar zie je de bonus niet meteen terug, kijk dan in het promoties overzicht van je account voordat je opnieuw probeert. Blijft de bonus daar ook uit, neem dan contact op met support en vermeld de gebruikte code, zodat het team kan nagaan wat er is misgegaan.
