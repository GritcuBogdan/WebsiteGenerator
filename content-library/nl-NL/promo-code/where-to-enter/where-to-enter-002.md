Wil je een {{PROMO_CODE}} gebruiken bij {{BRAND_NAME}}, dan is het aanmeldformulier vaak de eerste plek waar je hem kunt invoeren. Tijdens de registratie staat meestal een apart veld met een omschrijving als promotiecode of bonuscode. Vul de code daar exact in, let op hoofdletters en spaties, en bevestig het formulier pas nadat je de invoer hebt gecontroleerd.

Wordt de code niet tijdens de registratie gevraagd, dan is dat geen probleem: veel aanbiedingen staan ook toe dat je de code later, bij je eerste storting, invoert. Het veld bevindt zich dan in de kassa, meestal vlak boven de knop waarmee je de betaling bevestigt.

Voer de code in ieder geval in vóórdat je de storting afrondt. Bij vrijwel alle aanbiedingen is een code die je pas na het versturen van de betaling invoert niet meer geldig. Controleer daarna in je account of de bijbehorende bonus als geactiveerd staat, zodat je zeker weet dat de code is verwerkt.
