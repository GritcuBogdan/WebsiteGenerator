De {{PROMO_CODE}} bij {{BRAND_NAME}} voer je meestal op een van twee momenten in: tijdens de registratie of bij je storting in de kassa.

| Moment | Waar |
| --- | --- |
| Registratie | Apart codeveld op het aanmeldformulier |
| Storting | Codeveld in de kassa, vóór het bevestigen |
| Account | Promoties overzicht, indien de code daar is toegestaan |

Voer de code exact in zoals hij is opgegeven, inclusief hoofdletters en cijfers. Bevestig daarna de invoer voordat je verdergaat, zodat de code aan je storting of registratie wordt gekoppeld. Een code die pas na de storting wordt ingevoerd, werkt bij veel aanbiedingen niet meer.
