De vanligaste anledningarna till att {{PROMO_CODE}} inte fungerar hos {{BRAND_NAME}} handlar sällan om tekniska fel, utan om hur och när koden används.

| Möjligt fel | Lösning |
| --- | --- |
| Extra mellanslag i koden | Kopiera och klistra in noggrant |
| Koden angiven för sent | Ange den innan insättningen bekräftas |
| Kod från en gammal kampanj | Kontrollera aktuell kampanjsida |
| Kontot redan använt en kod | De flesta koder gäller endast en gång |

Fungerar koden fortfarande inte efter kontroll av ovanstående, kontakta support med koden och tidpunkten för försöket.
