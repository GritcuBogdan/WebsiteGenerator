En {{PROMO_CODE}} hos {{BRAND_NAME}} fungerar som en nyckel som låser upp ett specifikt erbjudande, snarare än att den i sig utgör bonusen. Koden måste oftast anges i ett särskilt fält, antingen vid registreringen eller i kassan, och den aktiverar bara det erbjudande den är kopplad till. Att skriva in fel kod, eller ingen kod alls, innebär vanligtvis att erbjudandet uteblir helt.

Koder kan ha ett bäst före datum, precis som andra kampanjer, så det lönar sig att kontrollera aktualiteten innan man förlitar sig på en kod som hittats på en äldre sida eller i ett gammalt mejl.
