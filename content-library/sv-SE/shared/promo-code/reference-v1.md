En kampanjkod hos {{BRAND_NAME}} kopplar ett erbjudande till en kontoåtgärd. Koden kan öppna en välkomstbonus, reload eller gratissnurr. Kontrollera aktivering, insättning, giltighet och gränser eftersom koden inte ersätter villkoren.

| Kontroll | Varför |
| --- | --- |
| Stavning | Koden kan kräva exakt skrivning |
| Konto | Vissa koder gäller bara nya medlemmar |
| Tidpunkt | Aktivering kan behövas före insättning |
| Betalning | Minsta insättning kan gälla |
| Resultat | Kontrollera att belöningen syns |

Om koden inte fungerar ska du inte skriva in den om och om igen. Kontrollera kampanjsidan och kontakta support med felmeddelandet.
