Innan du kontaktar support hos {{BRAND_NAME}} kan det löna sig att kontrollera några vanliga orsaker själv.

| Symptom | Möjlig orsak |
| --- | --- |
| Sidan laddar långsamt | Anslutning eller belastning hos leverantören |
| Knappar reagerar inte | Föråldrad webbläsare eller blockerad javascript |
| Utloggad utan förvarning | Inaktivitet eller säkerhetsåtgärd |
| Fel visas vid insättning | Betalmetodens egna begränsningar |

Om inget av det ovanstående löser problemet, kontakta support med en tydlig beskrivning. Ju mer specifik beskrivningen är, desto snabbare går det att hitta en lösning.
