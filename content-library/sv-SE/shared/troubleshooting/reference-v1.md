Kontoproblem hos {{BRAND_NAME}} kan ofta begränsas genom att kontrollera felmeddelande, enhet och åtgärd. Kontrollera anslutning, webbläsare och kontomeddelanden. Upprepa inte en betalning medan den första fortfarande väntar.

| Problem | Första kontroll |
| --- | --- |
| Inloggning nekas | E post, lösenord och återställning |
| Spel laddar inte | Webbläsare, anslutning och titelstatus |
| Saldo verkar fel | Aktivitet, betalning och valuta |
| Betalning väntar | Kassameddelande och behandlingstid |
| Konto begränsat | Verifiering eller säkerhetsmeddelande |

Om problemet kvarstår antecknar du tid, enhet och meddelande och skickar uppgifterna från den registrerade adressen. Bifoga inte lösenord eller fullständigt kortnummer.
