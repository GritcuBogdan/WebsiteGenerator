Om du glömmer lösenordet hos {{BRAND_NAME}} använder du återställningslänken på den officiella inloggningen. Ange registrerad e post och kontrollera även skräppost. Öppna länken endast när avsändare och adress stämmer.

| Fas | God vana |
| --- | --- |
| Begäran | Använd registrerad e post |
| Meddelande | Kontrollera avsändaren |
| Nytt lösenord | Välj ett unikt lösenord |
| Kontroll | Granska aktivitet efter inloggning |
| Hjälp | Kontakta support om inget kommer |

Dela inte återställningslänken. Vid ett oväntat meddelande byter du lösenord via den officiella sidan och rapporterar händelsen.
