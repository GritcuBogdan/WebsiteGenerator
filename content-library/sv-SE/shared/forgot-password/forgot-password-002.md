Ett bortglömt lösenord hos {{BRAND_NAME}} löses snabbast genom den inbyggda återställningsfunktionen, inte genom att gissa sig fram eller kontakta support i onödan.

| Situation | Rätt åtgärd |
| --- | --- |
| Lösenordet glömt | Använd länken för återställning |
| Mejlet kommer inte fram | Kontrollera skräppost, vänta någon minut |
| Länken har gått ut | Begär en ny återställningslänk |
| Nytt lösenord vald | Logga in som vanligt igen |

Dela aldrig återställningslänken med någon annan, och byt lösenord omedelbart om du misstänker att någon annan känner till det gamla.
