Gratissnurr hos {{BRAND_NAME}} ger ett bestämt antal rundor utan separat insats. Kontrollera antal, spel, giltighet, hur vinster omvandlas och vilket omsättningskrav som gäller.

| Detalj | Vad du kontrollerar |
| --- | --- |
| Antal | Hur många snurr som krediteras |
| Titel | I vilket spel de fungerar |
| Giltighet | När oanvända snurr försvinner |
| Vinst | Kontanter eller bonusbalans |
| Omsättning | Vilket krav som gäller för resultatet |

Använd snurren i den angivna titeln och läs kampanjsidan före start. Gratissnurr är ett sätt att prova ett spel och ingen vinstgaranti.
