Integritetsinformationen hos {{BRAND_NAME}} bör förklara vilka kontouppgifter som samlas in, varför de behövs och hur länge de sparas. Registreringsuppgifter stödjer konto och kontroll. Betalningshistorik hjälper vid behandling och bedrägerikontroll.

| Dataområde | Vanligt syfte |
| --- | --- |
| Konto | Inloggning, profil och kommunikation |
| Dokument | Ålder, identitet och adress |
| Betalningar | Insättningar, uttag och avstämning |
| Teknik | Säkerhet och felsökning |
| Support | Frågor och klagomål |

Läs den aktuella policyn före registrering. Använd den angivna kontaktvägen för frågor om uppgifter och skicka dokument endast genom en bekräftad kanal.
