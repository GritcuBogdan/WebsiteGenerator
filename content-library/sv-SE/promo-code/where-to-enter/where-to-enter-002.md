Var {{PROMO_CODE}} ska anges hos {{BRAND_NAME}} beror på om koden hör till registreringen eller till en specifik insättning.

| Tillfälle | Var koden anges |
| --- | --- |
| Ny registrering | Fältet för kampanjkod i formuläret |
| Insättning i efterhand | Motsvarande fält i kassan |
| Kampanj via länk | Kan fyllas i automatiskt, kontrollera ändå |
| Support | Kan i undantagsfall registrera koden manuellt |

Ange koden innan du bekräftar insättningen, eftersom den sällan går att lägga till i efterhand när betalningen redan är genomförd.
