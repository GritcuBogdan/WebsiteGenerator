Innan du begär ett uttag hos {{BRAND_NAME}} är det bra att känna till gränserna för den metod du valt bland {{WITHDRAWAL_METHODS}}.

| Faktor | Vad som varierar |
| --- | --- |
| Minsta uttag | Skiljer sig mellan betalmetoder |
| Högsta uttag | Kan gälla per transaktion eller per period |
| Behandlingstid hos sajten | Oftast inom ett dygn efter godkännande |
| Tid hos betalleverantören | Beror på vald metod |
| Första uttaget | Kan ta längre tid på grund av verifiering |

Kontrollera den aktuella gränsen för din valda metod i kassan innan du begär uttaget, eftersom värdena kan ändras över tid.
