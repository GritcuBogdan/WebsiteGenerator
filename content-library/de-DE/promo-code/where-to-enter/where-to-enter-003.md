Wird der Code {{PROMO_CODE}} bei {{BRAND_NAME}} nicht angenommen, liegt das selten an der Eingabestelle selbst, sondern meist an Zeitpunkt oder Schreibweise. Manche Codes sind nur bei der Registrierung gültig und lassen sich später nicht mehr im Kontobereich nachtragen. Andere Codes sind wiederum an eine Einzahlung gebunden und müssen erst in der Kasse eingegeben werden.

Bevor Sie den Support kontaktieren, prüfen Sie deshalb, ob der Code für den aktuellen Schritt überhaupt vorgesehen ist, ob das Ablaufdatum bereits erreicht wurde und ob die Eingabe exakt der Vorlage entspricht. Erst wenn diese Punkte ausgeschlossen sind, lohnt sich eine Nachricht an den Support mit der genauen Fehlermeldung.
