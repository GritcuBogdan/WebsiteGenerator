Je nach Situation gibt es bei {{BRAND_NAME}} unterschiedliche Stellen, an denen der Code {{PROMO_CODE}} eingetragen werden kann.

| Zeitpunkt | Ort der Eingabe |
| --- | --- |
| Bei der Registrierung | Eigenes Feld im Anmeldeformular |
| Nach der Registrierung | Bonusbereich im Konto |
| Bei der Einzahlung | Eingabefeld in der Kasse |

Wichtig ist, den Code an nur einer Stelle einzutragen und das Ergebnis dort zu prüfen, bevor er an anderer Stelle erneut eingegeben wird. Eine doppelte Eingabe löst keine zusätzliche Gutschrift aus und kann in seltenen Fällen zu einer Fehlermeldung führen.
