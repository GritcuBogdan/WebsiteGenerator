Der Promo Code {{PROMO_CODE}} von {{BRAND_NAME}} wird üblicherweise direkt im Registrierungsformular eingetragen, in einem eigenen Feld, das oft mit „Promo Code“ oder „Aktionscode“ beschriftet ist. Wer die Registrierung bereits ohne Code abgeschlossen hat, findet ein entsprechendes Feld häufig auch im Kontobereich oder beim ersten Einzahlungsvorgang in der Kasse.

Der Code sollte genau wie angegeben eingetragen werden, da Groß- und Kleinschreibung oder zusätzliche Leerzeichen die Eingabe ungültig machen können. Nach dem Eintragen bestätigt eine Meldung im Formular oder in der Bonusübersicht, ob der Code angenommen wurde. Bleibt diese Bestätigung aus, lohnt sich ein zweiter Blick auf Schreibweise und Ablaufdatum, bevor der Code erneut eingegeben wird.
