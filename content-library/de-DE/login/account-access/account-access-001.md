Der Kontozugang bei {{BRAND_NAME}} beginnt mit der E-Mail-Adresse und dem Passwort aus der Registrierung. Öffnen Sie die Anmeldeseite, tragen Sie beide Angaben sorgfältig ein und senden Sie das Formular einmal ab. Wiederholte Versuche mit einem alten Passwort können eine kurze Sicherheitssperre auslösen.

Nach der Anmeldung sollten Sie zuerst Guthaben, Währung und die letzten Aktivitäten prüfen. Dabei können Sie eine offene Verifizierung, eine ausstehende Zahlung oder eine noch aktive Aktion erkennen. Im Konto sollten außerdem Profil, Einzahlungslimits, Auszahlungshistorie und die Werkzeuge für verantwortungsbewusstes Spielen erreichbar sein.

| Prüfung | Sinnvolle Handlung |
| --- | --- |
| E-Mail-Adresse | Genau die registrierte Adresse verwenden |
| Passwort | Keine alten Autofill Daten übernehmen |
| Gerät | Öffentliche Computer vermeiden und danach abmelden |
| Sicherheitshinweis | Die Meldung vor dem Spielbeginn lesen |
| Fehlversuch | Die Passwortwiederherstellung nutzen statt weiter zu raten |

Speichern Sie das Passwort nicht auf einem gemeinsam genutzten Gerät. Wenn der Zugang nach der Wiederherstellung weiterhin nicht funktioniert, schreiben Sie den Support von der registrierten Adresse aus an. Senden Sie niemals ein Passwort oder die vollständige Kartennummer.
