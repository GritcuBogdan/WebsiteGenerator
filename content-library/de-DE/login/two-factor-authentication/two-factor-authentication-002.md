Die Einrichtung der Zwei Faktor Authentifizierung bei {{BRAND_NAME}} lässt sich in wenige Schritte unterteilen.

| Schritt | Handlung |
| --- | --- |
| 1 | Option in den Sicherheitseinstellungen öffnen |
| 2 | QR Code mit einer Authentifizierungs App scannen |
| 3 | Ersten Code zur Bestätigung eingeben |
| 4 | Wiederherstellungscodes sicher speichern |
| 5 | Bei der nächsten Anmeldung Code eingeben |

Funktioniert der Code bei der Anmeldung nicht, prüfen Sie zunächst, ob die Uhrzeit des Geräts korrekt eingestellt ist, da viele Apps zeitbasierte Codes erzeugen. Bleibt das Problem bestehen, hilft ein gespeicherter Wiederherstellungscode oder eine Nachricht an den Support von der registrierten Adresse aus.
