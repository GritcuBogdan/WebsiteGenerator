Ein Code, der bei {{BRAND_NAME}} nicht angenommen wird, lässt sich meist anhand weniger Punkte erklären.

| Ursache | Prüfung |
| --- | --- |
| Falsche Schreibweise | Code Zeichen für Zeichen mit der Vorlage vergleichen |
| Abgelaufener Code | Gültigkeitsdatum der Aktion prüfen |
| Falscher Zeitpunkt | Prüfen, ob der Code vor der Einzahlung nötig ist |
| Nicht qualifiziertes Konto | Bedingungen zur Teilnahme lesen |

Erst wenn diese Punkte ausgeschlossen sind, lohnt sich eine Nachricht an den Support mit der genauen Fehlermeldung und dem verwendeten Code.
