Ein Promo Code bei {{BRAND_NAME}} ist meist an eine bestimmte Aktion gebunden und lässt sich nicht beliebig mit anderen Angeboten kombinieren. Wird ein Code eingegeben, während bereits eine andere Aktion aktiv ist, kann es sein, dass nur eine der beiden Aktionen gutgeschrieben wird.

Vor der Eingabe lohnt sich deshalb ein Blick darauf, welche Aktion der Code tatsächlich auslöst und ob eine bereits aktive Aktion dadurch ersetzt wird. Bei Unklarheiten hilft ein Blick in die Aktionsseite oder eine kurze Nachricht an den Support, bevor der Code eingegeben wird.
