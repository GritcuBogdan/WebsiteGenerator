Ein Promo Code bei {{BRAND_NAME}} verbindet eine Kampagne mit einer bestimmten Kontoaktion. Er kann einen Willkommensbonus, eine Nachladeaktion oder Freispiele aktivieren. Der Code ersetzt nicht die Bedingungen. Prüfen Sie Einzahlung, Aktivierungszeitpunkt, Frist und Limit.

| Prüfung | Warum sie wichtig ist |
| --- | --- |
| Schreibweise | Codes müssen oft exakt eingegeben werden |
| Kontostatus | Manche Codes sind nur für neue oder ausgewählte Konten gültig |
| Zeitpunkt | Ein Code kann vor der Einzahlung aktiviert werden müssen |
| Zahlung | Die Kampagne kann eine Mindesteinzahlung verlangen |
| Ergebnis | Prüfen, ob die Gutschrift sichtbar ist |

Wenn der Code nicht funktioniert, geben Sie ihn nicht mehrfach ein. Prüfen Sie Aktionsseite und Ablaufdatum und wenden Sie sich mit der Fehlermeldung an den Support.
