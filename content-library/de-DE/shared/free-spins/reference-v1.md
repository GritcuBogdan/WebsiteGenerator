Gratis Spins bei {{BRAND_NAME}} geben eine festgelegte Anzahl von Runden ohne separaten Einsatz. Neben der Anzahl zählen das ausgewählte Spiel, die Frist, die Umwandlung der Gewinne und die Umsatzregel.

| Detail | Was zu bestätigen ist |
| --- | --- |
| Anzahl | Wie viele Spins gutgeschrieben werden |
| Spiel | Welcher Titel die Spins akzeptiert |
| Ablauf | Wann ungenutzte Spins verfallen |
| Gewinne | Echtgeld oder Bonusguthaben |
| Umsatz | Welche Bedingung für Gewinne gilt |

Nutzen Sie die Spins nur im genannten Titel und prüfen Sie die Aktionsseite, bevor Sie beginnen. Die Spins sind eine Möglichkeit zum Testen, aber keine Gewinnzusage und kein Grund für weitere Einzahlungen.
