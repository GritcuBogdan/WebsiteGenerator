Mobiles Spielen bei {{BRAND_NAME}} läuft im responsiven Browser. Lobby, Kasse, Konto, Support und Spielerschutz sollten auch auf dem kleinen Bildschirm erreichbar bleiben.

| Prüfung | Warum sie wichtig ist |
| --- | --- |
| Browser | Eine aktuelle unterstützte Version verwenden |
| Verbindung | Stabilität verhindert unterbrochene Aktionen |
| Bedienung | Buttons und Gewinnplan müssen lesbar bleiben |
| Kasse | Einzahlungen und Auszahlungen ohne Desktop Ansicht erreichbar |
| Sicherheit | Gerätesperre und privates Netzwerk nutzen |

Öffnen Sie vor einer längeren Sitzung ein Spiel, die Kasse und den Support. Verwenden Sie kein öffentliches WLAN für Zahlungen und melden Sie sich danach ab. Die mobile Nutzung ändert nichts an Ihrem vorher festgelegten Budget.
