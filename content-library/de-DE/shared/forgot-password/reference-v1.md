Wenn Sie das Passwort für {{BRAND_NAME}} vergessen haben, nutzen Sie den Wiederherstellungslink auf der offiziellen Anmeldeseite. Geben Sie die registrierte E Mail ein und prüfen Sie auch den Spam Ordner. Öffnen Sie den Link nur, wenn Absender und Adresse zum offiziellen Dienst passen.

| Schritt | Gute Praxis |
| --- | --- |
| Anfrage | Registrierte Adresse verwenden |
| Nachricht | Absender vor dem Öffnen prüfen |
| Neues Passwort | Ein eigenes Passwort verwenden |
| Kontrolle | Nach der Anmeldung letzte Aktivität prüfen |
| Hilfe | Support kontaktieren, wenn keine Nachricht ankommt |

Teilen Sie den Link nicht. Bei einer unerwarteten Nachricht ändern Sie das Passwort über die offizielle Seite und melden den Vorfall.
