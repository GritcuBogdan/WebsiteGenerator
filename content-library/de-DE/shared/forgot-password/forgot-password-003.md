Kommt nach der Anfrage zur Passwortwiederherstellung bei {{BRAND_NAME}} keine Nachricht an, liegt das meist an einer der folgenden Ursachen.

| Ursache | Lösung |
| --- | --- |
| Falsche E-Mail-Adresse eingetragen | Registrierte Adresse noch einmal prüfen |
| Nachricht im Spam Ordner | Ordner manuell durchsuchen |
| Verzögerte Zustellung | Einige Minuten abwarten, bevor erneut angefragt wird |
| Adresse nicht mehr erreichbar | Support über einen anderen Kanal kontaktieren |

Erhalten Sie die Nachricht schließlich, öffnen Sie den Link zeitnah, da er nach einer bestimmten Frist abläuft. Nach der Vergabe eines neuen Passworts sollte die letzte Kontoaktivität kurz überprüft werden.
