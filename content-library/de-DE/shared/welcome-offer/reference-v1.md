Das Willkommensangebot von {{BRAND_NAME}} sollte als Paket mit mehreren Bedingungen gelesen werden. Prüfen Sie Höchstbonus, qualifizierende Einzahlung, Umsatzregel, Laufzeit und Spiele, die zum Umsatz beitragen. Ein kleineres Angebot mit klaren Bedingungen kann praktischer sein als ein größerer Bonus mit kurzer Frist.

| Detail | Zu prüfende Frage |
| --- | --- |
| Bonuswert | Welcher Betrag wird nach der Einzahlung gutgeschrieben? |
| Mindesteinzahlung | Welche Einzahlung aktiviert die Aktion? |
| Spielbeitrag | Welche Spiele zählen zur Bedingung? |
| Laufzeit | Wie lange bleibt das Guthaben aktiv? |
| Auszahlung | Was muss vor der Auszahlung erfüllt sein? |

Lesen Sie die Aktion vor der Einzahlung und notieren Sie die aktuellen Bedingungen. Wenn die Aktion nicht zu Ihrem Budget passt, lehnen Sie sie ab, statt den Betrag zu erhöhen.
