{{BRAND_NAME}} sooduskood seob kampaania kindla kontotegevusega. See võib parandada tervitusboonust, avada reload-pakkumise, lisada tasuta keerutusi või tähistada lühiajalist kampaaniat. Kood ei asenda kampaania tingimusi. Kontrolli enne sisestamist sobivat sissemakset, aktiveerimise etappi, aegumist ja mis tahes piirangut.

| Koodi kontroll | Miks see on oluline |
| --- | --- |
| Kirjapilt | Koodid on tavaliselt tõstutundlikud ja tuleb sisestada täpselt |
| Konto staatus | Mõni kood kehtib ainult uutele kontodele või valitud liikmetele |
| Ajastus | Kood võib aeguda või vajada aktiveerimist enne sissemakset |
| Makse | Kampaania võib nõuda minimaalset sobivat summat |
| Tulemus | Kinnita, et krediit ilmub enne mängimise alustamist |

Kui kood ei rakendu, ära sisesta seda korduvalt. Kontrolli uuesti kampaanialehte, konto staatust, makse etappi ja aegumiskuupäeva. Võta ühendust klienditoega, esitades koodi kategooria ja kuvatud vea, kuid ära kunagi lisa sõnumisse parooli ega täielikku maksekaardi numbrit.
