A {{PROMO_CODE}} at {{BRAND_NAME}} acts as a simple trigger that connects a specific account action, such as registering or making a deposit, to a particular promotional campaign. Rather than replacing the terms of the promotion itself, the code exists mainly to identify which offer a player intends to claim, which matters when a platform runs more than one campaign at a time. Entering the correct code ensures the right offer is applied rather than a default or unrelated one.

Codes are almost always case sensitive and need to be entered exactly as published, whether that is on a promotions page, in a marketing email, or through a partner site. A code that is expired, mistyped, or restricted to a specific player group, such as new accounts only, will typically fail to apply and display an error rather than applying incorrectly. If this happens, rechecking the source of the code and confirming it is still valid for the current account status is the first thing to try.

Because a single mistyped character is the most common reason a code fails, copying and pasting the code directly, rather than retyping it from memory, is a simple habit that avoids most issues.
