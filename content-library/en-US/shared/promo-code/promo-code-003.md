Using a {{PROMO_CODE}} at {{BRAND_NAME}} correctly comes down to two things: entering it in the right place, and entering it exactly as published. Codes are typically distributed through the promotions page, marketing emails, or partner sites, and each one is generally tied to a specific offer, meaning it cannot simply be swapped for a different campaign's code and expected to work the same way.

Because these fields are usually case sensitive, small differences such as an extra space or a lowercase letter where an uppercase one was intended are enough to cause the code to be rejected. If a code does not apply, the platform will typically display an error rather than silently ignoring it, which makes it fairly easy to notice something has gone wrong before proceeding with a deposit under the wrong assumption.

It is also worth checking that the code is still valid for the intended purpose. Some codes are restricted to new accounts only, while others are time limited or tied to a minimum qualifying deposit. Reviewing the terms published alongside the code, rather than assuming it behaves like a previous one, is the most reliable way to use it successfully on the first attempt.
