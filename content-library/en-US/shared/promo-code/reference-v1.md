A promotion code at {{BRAND_NAME}} links a campaign to a particular account action. It may improve a welcome offer, unlock a reload, add free spins, or identify a short term campaign. The code does not replace the promotion terms. Check the qualifying deposit, activation stage, expiry, and any limit before entering it.

| Code check | Why it matters |
| --- | --- |
| Spelling | Codes are normally case sensitive and must be entered exactly |
| Account status | Some codes are for new accounts or selected members only |
| Timing | A code may expire or require activation before a deposit |
| Payment | The campaign can require a minimum qualifying amount |
| Result | Confirm the credit appears before starting to play |

If a code fails, do not enter it repeatedly. Recheck the campaign page, account status, payment stage, and expiry date. Contact support with the code category and the displayed error, but never include a password or full payment card number in the message.
