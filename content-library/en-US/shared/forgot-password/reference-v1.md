If you forget the password for {{BRAND_NAME}}, use the password recovery link on the official sign in form. Enter the registered email address and check the inbox, including the spam folder, for the recovery message. Open the link only if the address and branding match the official service.

| Recovery stage | Good practice |
| --- | --- |
| Request | Use the email connected to the account |
| Message | Check sender details before opening a link |
| New password | Use a unique password that is not used elsewhere |
| Confirmation | Sign in once and review recent account activity |
| Follow up | Contact support if no message arrives after checking the address |

Do not share the recovery link or password with another person. If you receive an unexpected reset message, change the password through the official page and report it. A short delay can occur after several requests, so allow the latest message time to arrive before starting another recovery attempt.
