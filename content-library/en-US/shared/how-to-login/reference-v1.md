Signing in to {{BRAND_NAME}} is a short process, but a careful check protects the account. Open the sign in page from the main navigation, enter the registered email and current password, and submit the form once. If an additional verification step appears, complete it through the official page rather than a link received from an unknown sender.

| Step | Action |
| --- | --- |
| 1 | Open the official sign in page |
| 2 | Enter the registered email address |
| 3 | Enter the current password without sharing it |
| 4 | Complete a requested security check |
| 5 | Review the account notice and balance after access |

If the details are rejected, use password recovery instead of repeating guesses. On a shared device, do not save the credentials and sign out at the end. A support agent should never ask for the password. If a sign in notice shows an unfamiliar device, change the password and report the event promptly.
