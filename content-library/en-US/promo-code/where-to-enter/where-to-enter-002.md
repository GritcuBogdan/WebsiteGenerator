There are generally a few places where the {{PROMO_CODE}} at {{BRAND_NAME}} can be entered, and knowing all of them helps if one option is not available for a particular offer.

Common places to enter a promotional code:
- The registration form, usually as an optional field near the end of the signup process
- The cashier page, alongside the deposit amount when making a first or subsequent payment
- The promotions tab within the account dashboard, particularly for offers not tied to a deposit
- A dedicated landing page linked from a marketing email or partner site, which sometimes applies the code automatically

Because the available entry point depends on the specific promotion, checking the terms attached to the code before assuming where it belongs is worth doing. A code intended for the registration form will generally not work if entered later at the cashier, and vice versa, so matching the code to its intended entry point avoids a wasted attempt. If a code fails to apply, retyping it carefully, since these fields are usually case sensitive, resolves the issue in most cases.
