Entering the {{PROMO_CODE}} at {{BRAND_NAME}} at the right moment makes the difference between a bonus applying successfully and a code going unused. In most cases, the field for entering a promotional code appears directly within the registration form, usually near the bottom alongside the terms and conditions checkbox. Filling it in at this stage links the code to the account before it is even created, so it is available as soon as the account is confirmed and a qualifying deposit is made.

If the code was not entered during signup, many platforms also provide a second opportunity at the cashier, where a promotional code field often appears alongside the deposit amount when making a payment. Entering it here before confirming the deposit allows the same linking to happen at the point of payment instead of at registration. Some platforms also allow codes to be entered from the promotions tab in the account dashboard, particularly for offers that are not tied to a first deposit.

Whichever entry point is used, double-checking that the code has been typed exactly as shown, since these fields are typically case sensitive, avoids the most common reason a code fails to apply.
