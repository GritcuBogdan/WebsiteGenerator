New players at {{BRAND_NAME}} sometimes assume a {{PROMO_CODE}} only applies during registration, but depending on the specific campaign, there can actually be more than one point at which it is accepted. The most common location is the signup form itself, where a code field typically sits near the final confirmation step. Entering it here ties the code to the account from the very start, which is the simplest and most reliable approach when a code is meant for new players specifically.

For campaigns aimed at existing accounts, such as a reload offer or a seasonal promotion, the code is more often entered at the cashier at the time of deposit, rather than during signup, since the account already exists. In this case, the code field usually appears just above the deposit amount before the payment is confirmed. A smaller number of promotions instead activate through the promotions tab of the account dashboard, where a code can be entered directly without going through the cashier at all.

If it is unclear which entry point applies, the terms published alongside the offer will specify it directly, and following that guidance is more reliable than guessing.
