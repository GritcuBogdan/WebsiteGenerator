Playing a slot at {{BRAND_NAME}} is simple, but a short preparation step makes the session easier to control. Start in the lobby and open the information panel for the title you are considering. Read the pay table, stake range, feature rules, and any maximum win note before selecting the real money mode.

| Step | Action |
| --- | --- |
| 1 | Choose a title and open its rules panel |
| 2 | Check the lowest stake and select a budget for the session |
| 3 | Use practice mode when you want to learn the controls first |
| 4 | Set the stake before spinning and avoid changing it after a loss |
| 5 | Pause when the budget or time limit you chose has been reached |

The spin button starts one result at a time. Auto play, where available, should only be used with a clear stop condition. Set a limit on the number of spins or the total loss before starting, and stop if the game begins to feel like a way to recover an earlier result. A feature round can change the balance quickly, so the same budget rule should remain in place after a win.

If a title freezes, the balance looks wrong, or a result does not settle, do not keep clicking the spin button. Save a screenshot, note the approximate time, and contact support. The game history and server record are more useful than repeated actions on the same screen.
