Account access at {{BRAND_NAME}} starts with the email address and password used during registration. Open the sign in form from the main menu, enter both details carefully, and submit the form once. Repeated attempts with an old password can trigger a temporary security pause, so allow the error message to finish before trying again.

If the account opens successfully, check the displayed balance, currency, and recent activity before starting a session. This quick review can reveal an unfinished verification request, a pending payment, or a promotion that is still active. The account area should also provide links to profile settings, deposit limits, withdrawal history, and responsible play controls.

| Access check | Recommended action |
| --- | --- |
| Correct email | Use the address registered to the account, including its exact spelling |
| Password entry | Type it manually if an autofill tool inserts an old value |
| Device security | Avoid signing in from a public computer and sign out after use |
| Account notice | Read any verification or security message before opening games |
| Failed attempt | Use password recovery instead of repeating guesses |

On a shared device, do not save the password in the browser and do not leave the cashier open. If the account remains inaccessible after recovery, contact support from the registered email address and include the time of the last successful sign in. Do not send a password or a full payment card number in a support message.
