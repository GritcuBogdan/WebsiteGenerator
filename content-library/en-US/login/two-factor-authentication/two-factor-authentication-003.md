Enabling two-factor authentication at {{BRAND_NAME}} is worth doing early, ideally soon after registering rather than after a security concern arises. The feature works by requiring a second piece of information beyond the password at login, usually a time-limited code generated by an app or delivered by text message. Setup takes place in the account security settings, where a short guided process connects the chosen method to the account, typically by scanning a QR code with an authenticator app and confirming the connection with a generated code.

Once active, every login will ask for this second code in addition to the password, which sounds like a minor inconvenience but meaningfully reduces the risk of unauthorized access, particularly if the password is ever exposed through an unrelated breach elsewhere. It is common for players to run into trouble later if the phone used for authentication is lost, replaced, or reset without transferring the authenticator app first, which is why saving the backup codes offered during setup, in a separate safe location, is a step worth not skipping.

If login becomes impossible because the second factor is unavailable, support can generally assist with recovery, though expect to confirm identity through the same verification process used elsewhere on the account.
