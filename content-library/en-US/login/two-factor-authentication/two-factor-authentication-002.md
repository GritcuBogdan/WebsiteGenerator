Setting up two-factor authentication for an account at {{BRAND_NAME}} is one of the more effective steps available for keeping the account secure, and it does not take long to configure.

Setting it up:
- Open the security section of the account settings after logging in
- Choose between text message codes or an authenticator app, with the app generally recommended for stronger security
- Scan the provided QR code or enter the setup key manually into the chosen authenticator app
- Enter the generated code back into the settings page to confirm the connection
- Save any backup codes provided during setup in a secure location for future use

Troubleshooting common issues:
- If a code is rejected, check that the device clock is set to the correct time, since authenticator apps rely on synced timing
- If access to the phone or app is lost, use the backup codes saved during setup, or contact support for identity-verified recovery
- If text messages are not arriving, confirm the registered phone number is current in the account settings

Keeping backup codes accessible but private is the simplest way to avoid being locked out later.
